# Academia

> Academia (Academia.edu, Academia Inc.) is a San Francisco based platform for sharing and discovering
> academic research, founded in 2008 by Richard Price. Researchers upload papers, build public profiles,
> follow research interests and track readership analytics; the company also runs the Academia journals
> program and sells Academia Premium subscriptions. Academia publishes no public developer program, API
> reference or machine-readable API specification.

## Status of the API surface

- Academia.edu has **no public API**, no developer portal and no published OpenAPI, AsyncAPI, GraphQL SDL
  or MCP server as of 2026-08-06.
- The `/v0/*` JSON endpoints referenced in `robots.txt` are the internal surface of Academia's own web
  client. They are `Disallow`ed to every crawler except three read-only paths
  (`/v0/users/*/following`, `/v0/users/*/coauthors`, `/v0/google_drive/notify_change`) and carry no
  published contract.
- The HTML site is served behind a Cloudflare managed challenge (`cf-mitigated: challenge`), so
  automated clients receive a 403 interstitial for `text/html` paths. `/robots.txt` and `/.well-known/*`
  are exempt.
